# AutoEDA and Retrieval Augmented Generation
Explore and Chat with your data records

This web application automates the process of exploratory data analysis, allowing users to quickly and easily identify patterns and trends in data sets. It provides a formal, literal level comprehension of the data, as well as a narrative summary of the analysis. The application also offers a first level revision of the analysis, allowing users to refine the results and gain further insight.

Plus, the [Cohere's](https://dashboard.cohere.com/api-keys) Command+R language model is optimized for conversational interactions and RAG workflows.

This provides an excellent means for complex tasks, such as writing product descriptions and answering questions.It is built in mind to handle use of discrete data and aid in the learning process.

Applications: Conversational AI, document understanding, and EDA, more.
